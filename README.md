# Simulasi Lapangan Zona Tunnel

Wisuda Oktober HMIF ITB 2026. Waktu simulasi 11.48.00–12.12.30.

Dibuat oleh Narendra Dharma Wistara M., Komandan Lapangan Zona Tunnel, bersama Defina Aurellia Ningsih (II’25), Superpips Komandan Lapangan Zona Tunnel.

Buka index.html melalui GitHub Pages. Model, gambar, font, dan pemutar telah disertakan dalam berkas tersebut. Tidak memerlukan npm atau server aplikasi.

## Batas penggunaan

Simulasi merupakan alat pemeriksaan alur. Konsistensi animasi tidak membuktikan kapasitas lokasi atau kelayakan waktu tempuh; keduanya perlu pengukuran dan pemeriksaan lapangan. Jumlah peserta sekitar 300 wisudawan, 400 massa, dan 120 pendamping; perangkat lapangan dihitung terpisah. Foto, oleat, dan logo berasal dari bahan panitia. Referensi dokumen tetap mengikuti izin akses pemiliknya.

## Pemeriksaan rilis

Perubahan terbaru mencakup navbar, judul, logo dan footer. Model serta data skenario tidak diubah pada revisi ini. Pemutar dan navigasi diperiksa melalui browser lokal; publikasi GitHub Pages dilakukan terpisah.
